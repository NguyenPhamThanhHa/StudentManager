# HỆ THỐNG QUẢN LÝ SINH VIÊN VÀ ĐĂNG KÝ HỌC PHẦN
# Giới thiệu
Hệ thống Quản lý Sinh viên và Đăng ký Học phần là ứng dụng được xây dựng bằng Java, nhằm hỗ trợ quản lý thông tin sinh viên, 
học phần và quá trình đăng ký môn học. Hệ thống giúp đơn giản hóa công tác quản lý trong các trường học, 
đồng thời đảm bảo tính chính xác và hiệu quả trong việc đăng ký học phần.
